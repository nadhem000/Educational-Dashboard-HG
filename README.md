# History & Geography Hub (HGH)

History and Geography lessons for all levels – part of the Educational Dashboard.

## Features

- Interactive history and geography quizzes
- Multi-language support (Arabic, English, French)
- Light / Dark theme
- Offline support (PWA)
- Shared user profile with the main Educational Dashboard (Supabase)

## Tech Stack

- Static HTML, CSS, JavaScript
- Supabase (auth, profile, analytics, push notifications)
- Netlify hosting

## Getting Started

1. Clone the repository
2. Make sure the shared scripts are present (see root dashboard)
3. Set up Supabase tables and edge functions (see `supabase_config.txt`)
4. Deploy to Netlify
